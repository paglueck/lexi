# Security policy

## Supported releases

Lexi has no stable release yet. Security fixes land on `main` and in the next pre-release
(`0.x`); older pre-releases are not patched.

Only list releases the maintainer actually supports. This project does not provide a guaranteed response time unless separately agreed.

## Report a vulnerability privately

Use the repository's **Security → Report a vulnerability** feature (GitHub private vulnerability reporting): https://github.com/paglueck/lexi/security/advisories/new. Do not create a public issue containing an exploit, credentials or confidential files.

Include the affected version, impact, reproduction steps using synthetic data and a minimal proof of concept where appropriate. Never send real customer translation files unless a secure, explicitly authorized process has been agreed.

The maintainer will assess the report and coordinate fixes and disclosure as capacity permits. Do not claim a guaranteed response or resolution deadline on behalf of the project.
